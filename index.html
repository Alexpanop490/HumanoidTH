Publishing & hosting

A GitHub Pages front door. A full app on Vercel.

This page is static and can be published with GitHub Pages. The complete Atlas uses Next.js server features and PostgreSQL, so its interactive routes and database need an application host. Deploy the repository to Vercel and configure the environment variables described in the README.
