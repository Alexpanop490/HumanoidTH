# Source Policy

Use official APIs and public feeds where available. Do not build risky scrapers for TikTok, Facebook, Instagram, X, Reddit, or private communities.

ThaiJO ingestion uses its public article-search API and stores article metadata, links, and abstracts only. Do not download or republish full-text PDFs without permission. Keep the publication year and original source URL with each analysis. Gemini-derived workplace, robot, interaction, emotion, response, and metric fields must remain traceable to abstract evidence; leave unreported details unknown.

Manual social records should contain URLs, source metadata, and short excerpts only when collection is permitted by platform terms and privacy expectations.

Adapters should fail gracefully when API keys are missing.
